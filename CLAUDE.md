# Vibecabulary

Menu bar glossary for macOS (1.0.0 released 2026-11-21 as a signed, notarized DMG on GitHub Releases). Bundle ID `com.vibecabulary.app`. Built with Swift Package Manager; see README for `scripts/build-app.sh`, `swift run GlossaryChecks` and `scripts/release.sh`.

- **Jira:** project `VIBE` on ariusvideo.atlassian.net. Releases are named "Vibecabulary 1.1"…
- **Confluence:** Vibecabulary space (`VC`): Roadmap, Requirements, Test Plans, Release Notes, App Store Launch, Website, Decisions Log.
- **Process:** Studio › How We Work in Confluence (Kanban; ticket key in branch, commits and PR title; Steven accepts work in In Review).
- **Current focus:** the Mac App Store launch epic (VIBE-1) and the "Generate your own glossary" story (VIBE-2).
- **Website:** vibecabulary.app source is in `~/Developer/vibecabulary-site`, not yet in this repo (VIBE-3).
